# CSS/JS 1차 분리

## 목적

`cart_group_calculator.html`에 inline으로 들어 있던 스타일과 화면 동작 코드를 외부 파일로 분리해 HTML 구조를 읽기 쉽게 만든다.

## 범위

- `<style>` 내용을 `assets/css/cart-group-calculator.css`로 이동
- `<script>` 내용을 `assets/js/cart-group-calculator.js`로 이동
- HTML은 CSS/JS 참조만 유지
- 테스트는 외부 JS 파일을 읽도록 수정
- GitHub Pages artifact에 `assets/` 포함

## 제외

- 계산 로직 모듈 분리
- ES module 전환
- React/Vue 마이그레이션
