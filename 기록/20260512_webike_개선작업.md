# 20260512 Webike Cart Splitter 개선 작업

## 범위

- CI 검증 진입점을 `npm test`로 통일
- 주문 그룹 추천 로직을 별도 모듈로 분리
- 엑셀 파일 선택 UI/파서 제거 상태 유지
- 상품URL 추출/내보내기/스크립트 흐름 보강
- 주문 그룹별 스크립트 복사 및 실행 상태 체크 UI 추가
- 추출 상품 수정 후 `수정 반영` 필요 상태 표시
- CSV ZIP과 Node CLI 입력 컬럼 왕복 검증 추가
- Playwright 기반 브라우저 E2E 검증 스크립트 추가
- XLSX `추출상품` 시트의 상품URL 셀 하이퍼링크 처리

## 검증 대상

- `npm test`
- `npm run test:e2e`는 Playwright 패키지와 Chromium 설치 후 실행

## 특이사항

- 인쇄용 XLSX 최적화는 제외하고, 화면/입력/자동화 연동 편의성 중심으로 정리했다.
- `product_url`이 있으면 Webike 상세 페이지를 바로 열고, 직접 입력은 부품번호 기준으로 단순하게 유지했다.
