# 2026-05-10 Webike 직접 입력 모드 기록

## 목적

Webike 장바구니 HTML을 복사하지 않아도 상품번호, 상품명, 수량, 단가 JPY를 직접 입력해 같은 주문 그룹 계산과 XLSX 내보내기를 사용할 수 있게 한다.

## 포함 범위

- 입력 방식 전환 추가
  - 장바구니 HTML
  - 직접 입력
- 직접 입력 테이블 추가
  - 상품번호
  - 상품명
  - 수량
  - 단가 JPY
- 직접 입력 행 추가/삭제
- 직접 입력값을 기존 계산용 상품 데이터로 정규화
- 기존 `recommendGroups`와 XLSX 출력 로직 재사용
- 직접 입력 정규화 테스트 추가
- README 사용법과 검증 항목 갱신

## 제외 범위

- Webike 로그인
- Webike 상품 검색
- 장바구니 자동 담기
- 환율 자동 조회
- CSV/XLSX 입력 파일 읽기
- 주문 또는 결제 자동화
