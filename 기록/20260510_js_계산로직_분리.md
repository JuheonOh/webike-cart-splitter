# JS 계산 로직 분리

## 목적

계산기 화면 동작 코드와 계산/파싱/XLSX 생성 코드를 분리해 테스트와 유지보수 범위를 명확히 한다.

## 변경

- `assets/js/calculator-core.js` 추가
- 계산, 장바구니 행 파싱, 직접 입력 정규화, CSV/TSV 파싱, 주문 그룹 추천, XLSX 생성 로직 이동
- `assets/js/cart-group-calculator.js`는 DOM, 화면 렌더링, 이벤트, 다운로드 트리거 중심으로 축소
- 브라우저에서는 `window.WebikeCartCore`로 core API 제공
- Node 테스트에서는 `require("../assets/js/calculator-core.js")`로 core API 직접 검증

## 유지

- `type="module"` 미사용
- 로컬 `file://` 실행 흐름 유지
- 기능 동작 변경 없음
