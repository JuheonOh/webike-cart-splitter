# 2026-05-10 Webike 분석 결과 직접 입력 반영 기록

## 목적

장바구니 HTML 분석으로 추출된 상품 목록을 직접 입력 테이블로 옮겨, 사용자가 상품명, 수량, 단가를 보정한 뒤 다시 계산할 수 있게 한다.

## 포함 범위

- 추출된 상품 영역에 `직접 입력으로 가져오기` 버튼 추가
- 분석 결과 상품 목록을 직접 입력 행 데이터로 변환
- 버튼 클릭 시 직접 입력 모드로 전환
- 직접 입력 테이블에 상품번호, 상품명, 수량, 단가 JPY 반영
- 기존 계산 로직과 XLSX 출력 로직 유지
- 분석 결과에서 직접 입력 행으로 변환되는 테스트 추가
- README 사용 흐름 갱신

## 제외 범위

- CSV/TSV 입력
- 브라우저 자동화 또는 크롤링
- 계산 로직 분리
- GitHub Pages/Actions

## 검증 시나리오

```bash
node tests/cart_group_calculator.test.js
```

브라우저 확인:

1. 장바구니 HTML을 붙여넣고 분석한다.
2. `직접 입력으로 가져오기`를 누른다.
3. 입력 모드가 직접 입력으로 전환되는지 확인한다.
4. 추출 상품이 직접 입력 테이블에 채워지는지 확인한다.
5. 값을 수정한 뒤 다시 분석할 수 있는지 확인한다.
