# 2026-05-10 Webike v0 안정화 기록

## 목적

현재 저장소를 Webike 주문 그룹 계산기의 v0 기준으로 정리한다.

v0는 자동화 도구가 아니라 로컬 주문 계획 보조 도구다. Webike 로그인, 검색, 장바구니 담기, 주문, 결제 자동화는 이번 범위에서 제외한다.

## 확정 범위

- 장바구니 HTML 붙여넣기 기반 상품 추출
- 수동 환율 입력
- 150 USD 기준 JPY 한도 계산
- 주문 그룹 추천
- XLSX 내보내기
- README 사용법과 검증 기준 추가
- 결과 렌더링 시 상품명/품번 HTML escape 처리
- 별도 의존성 없는 Node 검증 스크립트 추가

## 제외 범위

- Python/Playwright 자동화 구현
- Webike 로그인
- 품번 검색
- 장바구니 자동 담기
- 환율 자동 조회
- 배송비, 포인트, 쿠폰 계산
- 주문 또는 결제 자동화

## 검증 시나리오

```bash
node tests/cart_group_calculator.test.js
```

검증 내용:

- 샘플 상품 합계 `42,699 JPY`
- 기본 환율 기준 JPY 한도 `23,893 JPY`
- 추천 그룹 합계 `21,350 / 21,349 JPY`
- XLSX ZIP 시그니처 생성
- 상품명/품번 HTML escape 처리
