# Webike 환율 자동 갱신

## 목적

GitHub Pages 배포 환경에서 USD/JPY 수입환율 기본값을 수동으로 갱신하지 않도록 한다.

## 설계

- GitHub Actions가 forwarder.kr 고시환율 페이지를 주기적으로 조회한다.
- 미국 USD, 일본 JPY의 수입환율만 파싱한다.
- 결과를 `data/exchange-rates.json`에 저장한다.
- 계산기는 로딩 시 JSON을 읽어 환율 입력값에 반영한다.
- 브라우저 저장 설정이 있으면 저장값을 우선 유지한다.

## 방어 조건

- 적용기간을 찾지 못하면 갱신 실패 처리한다.
- USD 또는 JPY 수입환율이 없거나 0 이하이면 갱신 실패 처리한다.
- 기존 JSON과 적용기간/환율이 같으면 기존 `updatedAt`을 유지해 불필요한 커밋을 줄인다.
- 계산기는 JSON 로딩 실패 시 기존 입력값으로 계속 동작한다.
