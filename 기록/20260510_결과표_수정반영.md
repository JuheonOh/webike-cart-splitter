# 결과표 수정 반영

## 목적

HTML 분석 후 직접 입력 테이블로 이동하지 않아도 `추출된 상품` 표에서 수량과 단가를 보정하고 주문 그룹을 다시 계산할 수 있게 한다.

## 설계

- `추출된 상품` 표의 수량, 단가 JPY 컬럼만 입력 필드로 변경한다.
- 상품번호, 상품명, 소계 JPY는 읽기 중심으로 유지한다.
- 입력 중에는 XLSX 내보내기를 비활성화한다.
- `수정 반영` 버튼을 눌렀을 때만 추천 주문 그룹과 요약을 재계산한다.
- `추천 주문 그룹` 표는 계산 결과이므로 직접 편집하지 않는다.
