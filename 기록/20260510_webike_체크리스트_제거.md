# 2026-05-10 Webike 체크리스트 제거 기록

## 목적

주문별 체크리스트가 추천 주문 그룹과 사실상 같은 내용을 반복하므로 제거한다.

## 변경 범위

- 주문별 체크리스트 화면 제거
- XLSX `체크리스트` 시트 제거
- 체크리스트 전용 테스트 제거
- 체크리스트 목업 파일 제거
- README와 기존 작업 기록에서 체크리스트 관련 현재 기능 설명 제거

## 유지 범위

- 추천 주문 그룹
- 추출 상품 목록
- CSV/TSV 붙여넣기 입력
- 장바구니 HTML 파싱 안정화
