# 2026-05-10 Webike 고우선순위 개선 기록

## 목적

장바구니 HTML 파싱 안정성과 붙여넣기 입력 절차를 우선 개선한다.

## 변경 범위

- 장바구니 상품 행 탐지 selector 확장
- 상품번호, 상품명, 수량, 단가, 소계 추출 fallback 추가
- `JPY`, `円`, `￥` 가격 표기 파싱 지원
- 직접 입력 화면에 CSV/TSV 붙여넣기 영역 추가
- 직접 입력 테이블 안에서 표 데이터를 바로 붙여넣는 흐름 추가
- 파싱, CSV/TSV 테스트 추가

## 제외 범위

- XLSX 파일 직접 읽기
- GitHub Pages 배포
- GitHub Actions 환율 갱신
- 계산 로직 파일 분리
- Webike 로그인/장바구니 자동 조작

## 검증

```bash
node tests/cart_group_calculator.test.js
```
