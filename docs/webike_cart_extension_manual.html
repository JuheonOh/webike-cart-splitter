위바이크 장바구니 자동화 사용 설명서

CSV로 부품번호와 수량을 넣으면 Webike에서 부품을 찾아 장바구니에 담는 크롬 확장 프로그램입니다.

대상 사이트: japan-webike.kr 브라우저: Chrome 입력 형식: CSV 또는 TSV
1. 설치하기 2. 실행하기 3. CSV 작성 4. 부품 찾기 5. 확인 필요 처리 6. 장바구니 담기 7. 장바구니 비우기 8. 자주 묻는 상황

1. 설치하기

  1. 전달받은 확장 프로그램 압축 파일을 원하는 위치에 압축 해제합니다.
  2. Chrome 주소창에 chrome://extensions를 입력합니다.
  3. 오른쪽 위의 개발자 모드를 켭니다.
  4. 압축해제된 확장 프로그램을 로드를 누릅니다.
  5. manifest.json 파일이 바로 들어 있는 폴더를 선택합니다.
설치 후 확장 프로그램 폴더를 삭제하거나 위치를 옮기면 Chrome에서 확장 프로그램을 읽지 못할 수 있습니다.

필요한 파일 구조

webike-cart-extension/
├── manifest.json
└── extension/
    ├── service-worker.js
    ├── content-script.js
    ├── content-style.css
    ├── icons/
    │   ├── icon16.png
    │   ├── icon32.png
    │   ├── icon48.png
    │   └── icon128.png
    └── fonts/
        └── D2Coding.woff2

2. 실행하기

  1. Chrome에서 https://www.japan-webike.kr/ 사이트를 엽니다.
  2. Chrome 오른쪽 위의 확장 프로그램 아이콘을 누릅니다.
  3. 작은 패널이 열리면 CSV를 입력하거나 CSV 파일을 업로드합니다.
Webike 사이트가 아닌 다른 사이트에서 아이콘을 누르면 Webike 사이트로 이동합니다.
이전 작업은 하루 안에 다시 열면 복원됩니다. 오래된 작업은 새 작업으로 시작됩니다.

3. CSV 작성

기본 양식은 아래처럼 작성합니다.

[부품번호],[수량],부품명
16016MAS670,1,파일럿스크류

컬럼 설명

컬럼 필수 여부 설명
부품번호 필수 실제로 Webike 검색에 사용하는 값입니다.
수량 선택 비워두면 1개로 처리합니다.
부품명 선택 사용자가 구별하기 쉽게 적는 메모입니다. 검색에는 사용하지 않습니다.

사용 가능한 부품번호 컬럼명

품번, 상품번호, 부품번호, 파츠번호를 모두 사용할 수 있습니다.

예시

부품번호,수량,부품명
13225ML0405,2,앞바퀴베어링
13011MV4305,1,
99103-MT2-0350,4,하이픈넣었을때
같은 부품번호가 여러 줄 있으면 수량을 합산해서 1개 처리 대상으로 묶습니다.

4. 부품 찾기

  1. CSV 입력칸에 데이터를 붙여넣거나 CSV 파일을 선택합니다.
  2. 부품 찾기 버튼을 누릅니다.
  3. 조회가 끝나면 상단에 처리 대상, 찾음, 확인 필요, 무시, 장바구니 추가 개수가 표시됩니다.
부품을 찾으면 찾은 부품 목록에 표시됩니다.
검색 결과가 여러 개이거나 확정할 수 없으면 못 찾은 부품 목록에 표시됩니다.

5. 확인 필요 부품 처리

못 찾은 부품에는 자동으로 하나로 확정하지 못한 항목이 표시됩니다.

  • Webike 검색 열기: 해당 부품번호 검색 결과를 새로 확인합니다.
  • 이 상품 선택: 후보 중 맞는 상품을 직접 선택합니다.
  • 재검색: 해당 부품만 다시 검색합니다.
  • 무시: 이번 작업에서 제외합니다.
  • 실패 CSV 복사: 확인이 필요한 부품 목록을 CSV로 복사합니다.
중고 상품은 자동 후보에서 제외됩니다.

6. 장바구니 담기

  1. 부품 찾기가 끝나고 담을 수 있는 부품이 있으면 장바구니 담기 버튼이 흔들립니다.
  2. 장바구니 담기를 누르면 찾은 부품을 Webike 장바구니에 추가합니다.
  3. 진행 중에는 장바구니 담는 중... 진행률이 표시됩니다.
Webike 로그인이 풀려 있으면 장바구니 담기에 실패할 수 있습니다. 이 경우 Webike에 로그인한 뒤 다시 실행합니다.

7. 장바구니 열기 / 전체 비우기

  1. 장바구니 열기를 누르면 Webike 장바구니 페이지로 이동합니다.
  2. 장바구니 페이지에서 장바구니 전체 비우기 버튼이 활성화됩니다.
  3. 버튼을 누르면 삭제 확인창이 뜹니다.
  4. 확인을 누르면 장바구니 항목을 순차적으로 삭제합니다.

삭제 결과는 아래처럼 표시됩니다.

[삭제 대상 2] [삭제 완료 2] [실패 0]
장바구니 전체 비우기는 되돌릴 수 없습니다. 삭제 전에 장바구니 내용을 확인하세요.

8. 자주 묻는 상황

부품번호의 0과 O가 헷갈립니다.

확장 프로그램은 CSV 입력, 부품번호, 후보 표시 영역에 D2Coding 폰트를 적용해 0과 O를 더 구분하기 쉽게 표시합니다.

부품 찾기를 다시 누르면 어떻게 되나요?

기존 검색 결과를 지우고 다시 찾을지 확인창이 뜹니다. 확인하면 기존 리스트가 지워지고 현재 입력값으로 다시 조회합니다.

CSV에 같은 부품번호가 여러 번 있으면 어떻게 되나요?

같은 부품번호는 수량을 합산해서 1개 처리 대상으로 묶습니다.

수량을 비워두면 어떻게 되나요?

수량은 1개로 처리됩니다.

부품명은 검색에 사용하나요?

사용하지 않습니다. 실제 검색은 부품번호로만 진행합니다.

버튼을 눌러도 반응이 이상합니다.

Chrome 확장 프로그램을 새로고침한 뒤 Webike 페이지도 새로고침합니다.

확장 프로그램 파일을 옮겨도 되나요?

설치 후에는 폴더 위치를 유지하는 것이 좋습니다. 폴더를 삭제하거나 옮기면 Chrome이 확장 프로그램을 찾지 못할 수 있습니다.
